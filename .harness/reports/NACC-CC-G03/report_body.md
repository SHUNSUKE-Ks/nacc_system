# NACC-CC-G03 — サイドバー整理・メモとノートブックの統合・写真・カタログのリセット

記録日: 2026-10-05。実行元: Claude Code。未コミット・未公開（本番には出していない）。

## やったこと

| 依頼 | 結果 |
|---|---|
| ブログ記事をメモに統合し、ノートブックの中に置く | メモに `notebookId`・`images`・`deletedAt` を追加。旧ブログ記事と旧ノートブックのページは、クラウドにつながった時に1度だけメモへ移す（元データは消さない。`fromBlogId`/`fromPageId` で二重移行を防ぐ）。ブログ記事はノートブック「ブログ記事」へ入る |
| サイドバーの並び | クイックメモ → 商品一覧・写真・カタログ・リーフレット・資料PDF → ノートブック（すべてのメモ／未分類／各ノートブック）→ ごみ箱 |
| ノートブックの＋ | 見出しの＋で作成。ノートブックにマウスを乗せると出る＋で1段入れ子。ダブルクリックで名前変更。右の数字は中のメモ数 |
| 写真（Gallery） | 新ページ。グループ「商品画像」（商品写真＋同梱画像、自動）と「2026_写真」（空）。グループ追加可。メモの「＋ 写真を貼る」で選べる |
| DB02/03/10 を一時非表示 | サイドバーから外した（画面・データは残す） |
| カタログ: チェックをリセット | 確認日の横。確認ダイアログ付き。状態だけ未確認へ。メモ・確認日・追加成分は残す |
| カタログ: タイトルと説明を触って編集 | header のタイトル・説明を contentEditable に。端末とクラウド（catalogChecks の __meta）へ保存 |
| 商品Gallery の改名 | 「商品一覧」。表示形式の「Gallery」も「カード」に |
| header の整理 | カタログ・リーフレット・メモ・資料PDF・中身のない検索欄を header から外した。残りは ☰・NACC・いまのページ名・ログイン・設定・PDF |
| リーフレット v2 採用・v1 削除 | 旧2カラム編集（`LeafletEditor.tsx`）を削除。編集はすべて Ver2.1。一覧の「＋ 作成」も Ver2.1 で作る |
| サイドバーの？ | 「メニューの使い方」吹き出し（HELP_SIDEBAR） |
| アイコン | 各項目に線画アイコン（aria-hidden）。ボタンに aria-label・aria-current |

ついでに直したもの: メモの削除をごみ箱経由に変更（完全削除は確認付き）。メモ・ノートブックのIDを手元で先に決めるよう変更（オフラインで「作っても開かない」状態になっていたため）。
